# **DATABASES**
___
Here you can find an explanation of how to create, manage and use Databases in the Cloud Console. The Cloud Console offers PostgreSQL, TimescaleDB, MySQL, MariaDB, MongoDB and Redis Databases with High Availability, Replicas, Backups to S3 storage, extensions, custom options and network endpoints (load balancers).

{{% notice note %}}
Database-as-a-Service feature in the Cloud Console is currently in beta.
